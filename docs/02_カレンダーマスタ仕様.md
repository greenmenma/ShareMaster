# 02. カレンダーマスタ仕様

## 親子関係（上書き）

カレンダーは木構造で、子は親の情報を引き継ぎ、必要な部分だけ上書きします。

```
本社
├─ 滋賀
│  └─ システムA
├─ 小牧
│  └─ システムB
└─ システムC
```

ある日の区分は次の順で決まります（後のものほど優先）。

1. **定休曜日**：最も近い祖先の設定を継承（どこにも設定がなければ土・日）
2. **祝日**：祝日マスタに登録された日。「祝日の扱い」は最も近い祖先の設定を継承（既定：休日）
3. **日別設定**：ルートから対象カレンダーまで順に適用し、**子の設定が最優先**

日別設定には次の 3 つを持てます。

| 項目 | 内容 |
| --- | --- |
| 日種別 | 稼働日・半日稼働・会社休日・夏季休暇・年末年始・特別休日 など（マスタで追加可能）。未指定なら区分は親に従う |
| 名称 | 例：創立記念日 |
| 特記事項 | 自由記述。**祖先の特記事項もすべて表示**（どのカレンダーの記載か併記） |

「親の設定に従う」を選ぶと、そのカレンダーの日別設定を削除して親の状態に戻ります。

## 配色

| 対象 | 日付の文字色 | 背景色 |
| --- | --- | --- |
| 日曜日 | 赤 | 薄い赤（休日の場合） |
| 土曜日 | 青 | 薄い青（休日の場合） |
| 祝日 | 赤 | 薄い赤 |
| 土日以外の定休日 | ― | グレー |
| 日別設定の休日 | 曜日に準ずる | 日種別の色（薄く） |
| 日別設定の稼働日（半日稼働など） | 曜日に準ずる | なし（種別色のラベル・下線） |

- このカレンダー自身で個別設定している日は、日付の横に紫の点を表示します。
- 特記事項がある日はメモアイコン（年表示ではオレンジの点）を表示します。

## 画面

### 一覧（データグリッド）

- 行＝日付、列＝カレンダー（ツリー順）。各セルに休日名・日種別を色付きで表示
- 表示単位：**すべて／年／月**（すべて＝データが存在する年の範囲、最大 10 年）
- 「特別な日のみ」：通常の土日を除き、祝日・個別設定・特記事項・定休曜日の違いがある日だけを表示（年・すべての既定）
- 表示カレンダーの絞り込み、下部に期間内の休日数、CSV 出力（Excel 対応の BOM 付き UTF-8）
- **セルをクリックすると編集ダイアログ**を開きます

### カレンダー表示

- 表示単位：**すべて／年／月**（URL に保持されるため共有・ブックマーク可能）
- 月：大きなカレンダー（休日名・特記事項を表示）
- 年：12 か月のミニカレンダー（月名クリックで月表示へ）
- すべて：年ごとのミニカレンダー
- 右側：表示期間の休日数・稼働日数、カレンダー情報（定休曜日・祝日の扱い・管理者・子カレンダー）、祝日・特記事項の一覧
- **日付をクリックすると編集ダイアログ**を開きます

### 編集ダイアログ

- 現在の状態と親の設定を並べて表示（どのカレンダーから継承しているかも表示）
- 単日設定に加え、**期間＋曜日指定の一括設定**（例：6 月の土曜日をすべて稼働日に）
- その日の変更履歴を表示
- 権限がない場合は閲覧のみ

## 権限

| 操作 | システム管理者 | カレンダー管理者 | その他 |
| --- | :-: | :-: | :-: |
| 閲覧 | ○ | ○ | ○ |
| カレンダーの新規追加・削除 | ○ | × | × |
| 親カレンダー・コードの変更 | ○ | × | × |
| 名称・説明・定休曜日・祝日の扱い・管理者の変更 | ○ | ○ | × |
| 日別設定の編集 | ○ | ○ | × |
| 日種別・祝日マスタの編集 | ○ | × | × |
| システム管理者の追加・削除 | ○ | × | × |
| データクリア・サンプルデータ挿入 | ○ | × | × |

- カレンダー管理者は、**管理するカレンダーとその子孫**を編集できます。
- システム管理者は複数人設定できます。システム管理者が 1 人もいない場合は、**最初にログインした利用者**がシステム管理者に登録されます（`Auth:BootstrapAdmins` を指定した場合は、起動時にその利用者が登録されます）。

## 利用者の選択（管理者の追加）

- システム管理者・カレンダー管理者の追加では、利用者を検索して一覧から選択します（自由入力は不可）。
- 検索先は認証方式で切り替わります。Windows 認証：**Active Directory**、Entra ID：**Microsoft Graph API**、開発環境：開発用ユーザーとログイン済みの利用者。
- 氏名・ユーザー名・メールアドレスの部分一致で、最大 30 件を表示します（部署も表示）。無効化された AD アカウントは表示しません。
- 画面に表示する利用者名は、AD／Entra ID の表示名（displayName）です。Windows 認証では、ログイン時に AD から表示名とメールアドレスを取得します（1 時間キャッシュ）。

## データ管理（システム管理者画面）

| 操作 | 内容 |
| --- | --- |
| サンプルデータ挿入 | 本社＞滋賀＞システムA などのサンプルカレンダーと日別設定を登録する。本社カレンダーの管理者は操作した本人。カレンダーが 1 件でもあれば実行できない |
| データクリア | カレンダー・日別設定・カレンダー管理者・日種別・祝日・通知・変更履歴をすべて削除し、日種別・祝日を初期値に戻す。**システム管理者と利用者は残す**。確認のため「クリア」の入力が必要 |

- どちらの操作も変更履歴に記録します（データクリア後は、クリアした記録だけが残ります）。

## 通知（検討中の要件への暫定対応）

- 親カレンダーの日別設定・定休曜日・祝日の扱いが更新されると、**子孫カレンダーの管理者**にアプリ内通知します（更新者本人は除く）。
- 管理者ごとに「通知を受け取る」を ON/OFF できます。
- 通知はヘッダーのベルとホーム画面に表示され、クリックで該当カレンダーを開きます。
- メール・Teams 通知は `NotificationService` に送信処理を追加することで拡張できます（今後の検討事項）。

## 変更履歴

- カレンダー設定・日別設定・日種別・祝日・システム管理者の追加／変更／削除を記録します。
- 変更前・変更後の内容（JSON）、更新者、日時を保持し、画面で差分を確認できます。
- カレンダーは論理削除のため、削除後も履歴は残ります。

## 祝日

- 「国民の祝日に関する法律」に基づき、指定年の祝日（振替休日・国民の休日を含む）を自動生成できます（2000〜2099 年）。
- 初回起動時に前年〜2 年後の祝日を自動登録します。
- 法改正や臨時の祝日は祝日画面から手動で追加・修正してください。
