# 01. システム概要

## 構成

```
                ┌──────────── ローカル開発（Aspire） ────────────┐
                │                                                  │
 ブラウザ ──▶ Vite 開発サーバー(client) ──/api──▶ ShareMaster.Server ──▶ SQLite ファイル
                │                                                  │
                └──────────────────────────────────────────────────┘

                ┌──────────────────── 本番 ────────────────────────┐
 ブラウザ ──▶ ShareMaster.Server（React の静的ファイルも配信） ──▶ SQLite（将来 Azure SQL Database 等）
   │                  ▲ JWT 検証
   └─ MSAL ──▶ Microsoft Entra ID
                └──────────────────────────────────────────────────┘
```

- 本番は **Server 1 つ** をデプロイするだけで、React のビルド成果物が `wwwroot` に同梱されます（`dotnet publish` 時に自動ビルド）。
- Aspire（`ShareMaster.AppHost`）はローカル開発専用で、Server は Aspire のライブラリに依存していません。接続文字列 `ConnectionStrings:ShareMasterDb` を受け取るだけです。

## フォルダ構成

```
ShareMaster/
├─ ShareMaster.slnx            ソリューション
├─ docs/                       資料
└─ src/
   ├─ ShareMaster.AppHost/     Aspire（ローカル開発専用）
   ├─ ShareMaster.Server/      ASP.NET Core Web API
   │  ├─ Auth/                 認証（Entra ID / 開発用擬似ログイン）・権限判定
   │  ├─ Contracts/            API の入出力 DTO
   │  ├─ Controllers/          Web API
   │  ├─ Data/                 EF Core（DbContext・エンティティ・DB 製品別マイグレーション・初期データ・データ移行）
   │  ├─ Domain/               業務ロジック（カレンダー解決・祝日計算）
   │  └─ Services/             アプリケーションサービス（更新・履歴・通知）
   ├─ ShareMaster.Server.Tests/ xUnit テスト
   └─ ShareMaster.Client/      React + TypeScript
      └─ src/
         ├─ api/               API クライアント・型・TanStack Query フック
         ├─ auth/              MSAL / 開発用ログイン
         ├─ components/        共通部品（月・年カレンダー、編集ダイアログ等）
         ├─ layout/            共有レイアウト（ヘッダー・メニュー・通知）
         ├─ pages/             画面
         └─ utils/             日付・配色・ツリー処理
```
