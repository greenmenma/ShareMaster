# 03. 開発環境

## 必要なもの

| ツール | バージョン | 備考 |
| --- | --- | --- |
| .NET SDK | 10.0 以上 | |
| Node.js | 22 以上 | npm 同梱 |
| コンテナランタイム | Docker Desktop / Podman | SQL Server コンテナ（エミュレーター）用 |
| IDE（任意） | Visual Studio 2026 / Rider / VS Code（C# Dev Kit） | |

Windows・Mac のどちらでも同じ手順でデバッグできます。

## 起動（Aspire）

```bash
# 初回のみ（React の依存パッケージ）
npm --prefix src/ShareMaster.Client install

dotnet run --project src/ShareMaster.AppHost
```

※ `npm install` を忘れても Aspire が起動時に自動実行します。

Aspire ダッシュボードで次のリソースが起動します。

| リソース | 内容 |
| --- | --- |
| `sql` | SQL Server コンテナ（データはボリューム `sharemaster-sql-data` に永続化） |
| `ShareMasterDb` | データベース |
| `server` | ASP.NET Core（起動時にマイグレーション適用・サンプルデータ投入） |
| `client` | Vite 開発サーバー（`/api` を server にプロキシ） |

- SQL Server の sa パスワードは Aspire が自動生成し、AppHost の user-secrets に保存します。
- API リファレンス（Scalar）：`server` の URL + `/scalar`

### IDE でのデバッグ

- **Visual Studio（Windows）**：`ShareMaster.slnx` を開き、`ShareMaster.AppHost` をスタートアッププロジェクトにして F5。
  React は `ShareMaster.Client`（.esproj）としてソリューションに含まれ、ソリューションのビルドで `npm install` / `npm run build` も実行されます。
- **Rider**：`ShareMaster.AppHost` の実行構成で Debug（Aspire プラグイン推奨）。
- **VS Code**：C# Dev Kit で `ShareMaster.AppHost` を起動。
- React は ブラウザの開発者ツール、または VS Code の「JavaScript Debug Terminal」でデバッグできます。

## 開発用ログイン

開発環境（`Auth:Mode=Development`）では Entra ID を使わず、ヘッダー右上のユーザーメニューからユーザーを切り替えられます。

| ユーザー | 役割（サンプルデータ） |
| --- | --- |
| 管理者 太郎（admin@dev.local） | システム管理者・本社の管理者 |
| 滋賀 花子（shiga@dev.local） | 滋賀・システムA の管理者 |
| 小牧 次郎（komaki@dev.local） | 小牧・システムB の管理者 |
| 一般 三郎（user@dev.local） | 閲覧のみ |

開発用ユーザーは `src/ShareMaster.Server/appsettings.Development.json` の `Auth:DevUsers` で変更できます。
本番環境（`ASPNETCORE_ENVIRONMENT=Production`）で `Development` モードを指定すると起動時にエラーになります。

## コンテナを使わない簡易起動（SQLite）

Docker が使えない環境向けに、SQLite で Server を起動できます（画面確認用。本番は SQL Server 系のみ）。

```bash
dotnet run --project src/ShareMaster.Server --launch-profile "sqlite (コンテナなし)"
npm --prefix src/ShareMaster.Client run dev
```

ブラウザで http://localhost:5173 を開きます。

## マイグレーション

```bash
dotnet tool restore
cd src/ShareMaster.Server
# モデル変更後に追加（接続先は不要）
ConnectionStrings__ShareMasterDb="Server=dummy" dotnet ef migrations add <名前> -o Data/Migrations
# 本番適用用の冪等 SQL スクリプト
ConnectionStrings__ShareMasterDb="Server=dummy" dotnet ef migrations script --idempotent -o migrate.sql
```

PowerShell では `$env:ConnectionStrings__ShareMasterDb="Server=dummy"` を先に実行してください。
